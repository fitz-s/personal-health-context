# Deployment templates, not installed services

The local agent must generate tested install/status/uninstall/backup/restore/rollback scripts for the actual Mac. The example plist intentionally contains unresolved paths and is not loadable as a finished deployment. No secret belongs in launchd arguments or EnvironmentVariables.

One secure-tunnel stdio owner starts its MCP subprocess. Avoid independently supervising the same subprocess twice. A periodic worker should acquire a DB lease and coalesce work. Mobile ingestion is a distinct authenticated route, not automatically provided by the MCP tunnel.

Resolve and validate data/profile paths before enabling any component. `config.example.toml` defaults model/worker/push/cloud off and profile synthetic. The installer should explicitly configure production, Keychain refs and safe shadow behavior after authorized live tests, not quietly enable a public endpoint or paid calls.
